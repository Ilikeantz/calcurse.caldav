Privacy Policy

```

Last updated: September 2026

Purpose

This application is used solely for personal synchronization between a Google Calendar account and the calcurse calendar application.

Data processing

Calendar data accessed through the Google Calendar API is used only for the purpose of synchronizing the user's personal calendar with calcurse.

Calendar data is not sold, shared with third parties, or used for advertising.

Storage

OAuth credentials and synchronized calendar data are stored locally on the user's computer. This application does not operate a server that stores or processes calendar data.

Third-party services

Google Calendar is used as the calendar service. The use of Google Calendar is subject to Google's own Privacy Policy.

Contact

This application is a personal project and does not provide services to other users.

```
